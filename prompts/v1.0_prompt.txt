## 2. AGENT IMPLEMENTATIONS

### Research Agent
TOOLS: Brave Search API, Firecrawl/Playwright, BeautifulSoup
INPUT: User query (e.g., "top 5 financial institutes $1B+ revenue")
LOGIC:
- Parse query → identify criteria (industry, revenue, timeframe)
- Search Google for matching companies
- For each result: scrape company website, LinkedIn, Crunchbase
- Extract: company name, revenue data, recent news, technology mentions, pain points
- Validate against criteria, rank by relevance
- Store in state.companies[]
OUTPUT: Structured company profiles with confidence scores

### Stakeholder Intelligence Agent  
TOOLS: Proxycurl API / LinkedIn scraper, Apollo.io API, Hunter.io
INPUT: state.companies[]
LOGIC:
- For each company: search LinkedIn for C-suite, VPs, Directors
- Filter by decision-making roles relevant to our services
- Scrape: name, title, email, recent posts, interests, tenure
- Score contacts by: seniority, engagement likelihood, access to budget
- Store in state.contacts[]
OUTPUT: Prioritized contact list per company

### Use Case Generation Agent
TOOLS: OpenAI GPT-4, web search for industry trends
INPUT: state.companies[i] + our_services_catalog
LOGIC:
- Analyze company's industry, size, tech stack, pain points
- Research current trends in their sector
- Match our services to their challenges
- Generate 3-5 specific use cases with:
  * Problem statement (their pain point)
  * Solution (our service application)
  * Expected ROI / value metrics
  * Implementation timeline
- Rank by: relevance, value potential, competitive advantage
- Store in state.use_cases[]
OUTPUT: Contextualized use cases per company

### Proposal Generation Agent
TOOLS: OpenAI GPT-4 with structured outputs
INPUT: state.use_cases[i] + state.companies[i] + state.contacts[i]
LOGIC:
- For each use case, generate 2-3 proposal variants:
  * Executive Summary version (1 page, high-level)
  * Technical Deep-Dive (detailed, for technical buyers)
  * ROI-Focused (metrics-heavy, for financial decision-makers)
- Personalize based on contact's role and seniority
- Include: problem, solution, deliverables, timeline, pricing tiers, case studies
- Store in state.proposals[]
OUTPUT: Multiple proposal variants per use case

### Outreach Content Agent
TOOLS: OpenAI GPT-4
INPUT: state.contacts[i] + state.proposals[i]
LOGIC:
- Analyze contact's profile, recent activity, communication style
- Generate multi-channel outreach:
  * Email sequence: initial + 2 follow-ups (spaced 3-5 days)
  * LinkedIn connection message + inmails
  * Call script with objection handling
- Adapt tone: formal for C-suite, conversational for mid-level
- Include personalization hooks from their recent posts/company news
- Store in state.outreach[]
OUTPUT: Ready-to-send outreach content

### Campaign Manager Agent (Orchestrator)
TOOLS: All agent tools + workflow control
LOGIC:
- Receives campaign request from user
- Routes tasks to appropriate agents in sequence
- Monitors progress, handles errors/retries
- Asks user for approval at key checkpoints:
  * After company research (approve company list)
  * After use case generation (select use cases to pursue)
  * Before outreach execution (review content)
- Maintains campaign state, generates progress reports
- Provides reasoning for all decisions

## 6. WORKFLOW IMPLEMENTATION

Campaign Execution Flow:
1. User creates campaign with query
2. Campaign Manager Agent activates Research Agent
3. Research Agent → finds companies → asks user approval
4. Approved companies → Stakeholder Agent → finds contacts
5. Contacts + Companies → Use Case Agent → generates use cases → user selects best
6. Selected use cases → Proposal Agent → creates variants
7. Proposals + Contacts → Outreach Agent → drafts content → user reviews
8. User sends outreach → track responses in Contact Manager

Use conditional routing:
- If confidence_score < 0.7, ask user for input
- If no contacts found, retry with different search
- If use case generation fails, research more company data

## 8. AUTONOMOUS AGENT LOGIC

Each agent must:
```python
class AutonomousAgent:
    def execute(self, task, context):
        # 1. UNDERSTAND
        parsed_task = self.understand_task(task, context)
        
        # 2. PLAN
        plan = self.create_plan(parsed_task)
        # Returns: [{step, tool, expected_output, fallback}, ...]
        
        # 3. EXECUTE WITH SELF-CORRECTION
        results = []
        for step in plan:
            result = self.use_tool(step.tool, step.params)
            quality = self.evaluate_result(result, step.expected_output)
            
            if quality < 0.6:
                result = self.retry_with_different_approach(step)
            
            results.append(result)
        
        # 4. SYNTHESIZE
        final_output = self.synthesize(results)
        
        # 5. REFLECT
        confidence = self.calculate_confidence(final_output)
        reasoning = self.explain_reasoning(plan, results, final_output)
        
        return {
            'output': final_output,
            'confidence': confidence,
            'reasoning': reasoning,
            'sources': self.get_sources()
        }
```
